# Security policy

SignalForge is a security portfolio lab and has not reached a production
stability guarantee. Please report suspected vulnerabilities privately to
ebraheemohamed26@gmail.com with reproduction steps, impact, and affected
version. Do not include real credentials or customer telemetry.

You should receive an acknowledgement within seven days. Please allow time for
triage and a coordinated fix before public disclosure.

Never connect the repository's response-plan objects directly to production
containment. They are intentionally non-executable and require human approval.
